# Data

## Source

This project uses the **Superstore Dataset** published on Kaggle by Shivam Amrutkar (`yesshivam007`).

Source:  
https://www.kaggle.com/datasets/yesshivam007/superstore-dataset

The original workbook contains three worksheets:

- Orders
- Returns
- People

## Modifications

For this project, the original workbook data was converted into separate CSV files and imported into an SQLite database for analysis using SQL, Python and Power BI.

The repository therefore contains modified or reformatted versions of the original data:

- `Orders.csv`
- `Returns.csv`
- `People.csv`
- `superstore.db`

No claim of ownership is made over the original dataset.
