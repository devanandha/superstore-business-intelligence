# Data

This directory contains the sample Superstore data used in the analysis:

- `Orders.csv`: order-level sales data
- `Returns.csv`: returned-order identifiers
- `People.csv`: regional manager mapping
- `superstore.db`: SQLite database containing the three corresponding tables

Before redistributing the dataset publicly, confirm that its original licence permits republication. The analytical code can also be used with a compatible locally supplied dataset.
